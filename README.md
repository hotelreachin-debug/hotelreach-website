# 🏨 HotelReach - Premium Hotel Booking Platform

## Overview
HotelReach is a modern, premium hotel booking and digital marketing platform connecting travelers with trusted hotels across India.

## ✨ Features

### For Travelers
- 🔍 **Advanced Hotel Search** - Search by city, dates, and guest count
- ⭐ **Featured Hotels** - Premium hotel listings with ratings and amenities
- 💬 **24/7 WhatsApp Support** - Direct booking assistance
- 📱 **Fully Responsive** - Works seamlessly on all devices
- 🎨 **Beautiful UI** - Modern blue, white, and gold design theme

### For Hotel Owners
- 📈 **Digital Marketing** - Promote hotels across multiple channels
- 🤝 **Zero Commission** - No monthly charges, pay only per booking
- 📊 **Booking Growth** - Increase direct bookings and occupancy rates
- 👥 **Dedicated Support** - Personal account management

**Option 2: Using CNAME Record (www subdomain)**
```
Type: CNAME
Name: www
Value: hotelreachin-debug.github.io
```

### Steps to Enable GitHub Pages

1. Go to Repository Settings
2. Scroll to **Pages** section
3. Under **Source**, select **Deploy from a branch**
4. Select **main** branch and **/root** folder
5. Click **Save**
6. Add your custom domain (hotelreach.in)
7. Check **Enforce HTTPS**
8. Wait for DNS verification (usually 15-30 minutes)
